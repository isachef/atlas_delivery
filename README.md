# Delivery App - Приложение для доставки еды

Мобильное приложение для заказа еды из различных ресторанов с функциями просмотра меню, добавления блюд в корзину, оформления заказа и отслеживания его статуса.

## Функциональность

### Просмотр ресторанов и меню
- Список ресторанов с фильтрацией по категориям
- Поиск ресторанов по названию
- Детальное представление каждого ресторана с информацией и меню
- Карточки блюд с изображениями, названиями, описаниями и ценами

### Корзина и заказы
- Добавление блюд в корзину
- Изменение количества блюд в корзине
- Очистка корзины
- Оформление заказа с выбором адреса доставки и способа оплаты
- Просмотр истории заказов и их статусов

### Профиль пользователя
- Авторизация пользователя
- Просмотр и редактирование личной информации
- Управление адресами доставки
- Управление способами оплаты
- Список избранных ресторанов

## Технические детали

### Архитектура
- Flutter с использованием Provider для управления состоянием
- Модульная структура с разделением на модели, провайдеры и экраны
- Локальное хранение данных с использованием SharedPreferences

### Основные компоненты
- **Модели**: User, Restaurant, Product, Cart, Order, Address, PaymentMethod
- **Провайдеры**: UserProvider, RestaurantProvider, CartProvider, OrderProvider
- **Экраны**: HomeScreen, RestaurantDetailScreen, CartScreen, CheckoutScreen, ProfileScreen, OrderSuccessScreen

## Запуск проекта

1. Установите Flutter SDK (версия 3.7.0 или выше)
2. Клонируйте репозиторий
3. Установите зависимости: `flutter pub get`
4. Запустите приложение: `flutter run`
